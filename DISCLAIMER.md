This repository is published **strictly for educational and research purposes** — to
demonstrate how DHCP-layer attacks work and, more importantly, how to defend against them.

## Authorized use only

The tools and scripts here perform **active network attacks** (DHCP starvation, rogue DHCP
service, and man‑in‑the‑middle interception). Running them against a network disrupts service
and intercepts other users' traffic.

You may run this code **only** when **all** of the following are true:

1. The network is a **legally owned or explicitly authorized, isolated lab environment**
   (e.g. GNS3, EVE‑NG, or a physically separated test LAN).
2. You have **written permission** from the owner of every device and network segment involved.
3. No production systems, third‑party networks, or non‑consenting users are affected.

## Prohibited use

Do **not** use this project against:

- Any network you do not own or lack explicit written authorization to test.
- Corporate, campus, public, residential, or ISP networks.
- Any environment where real users' traffic could be intercepted or service disrupted.
